### 3. Структура репозитория

### 4. Распределение обязанностей

Обязанности распределены с учётом ролей из самостоятельной работы №1. Лидер отвечает за настройку репозитория, контроль структуры, ревью и слияние изменений. Каждый участник отвечает за изменения в своей области и создаёт осмысленные коммиты.

Подробное распределение приведено в `docs/raci-matrix.md`.

### 5. Коммиты

Добавить скриншоты истории коммитов с указанием авторов в `assets/`.

### 6. Pull Request и ревью

Для каждого участника создать отдельную ветку, внести изменения, выполнить `push`, создать Pull Request и получить ревью другого участника. Добавить скриншоты в `assets/`.

### 7. Вывод

Git и GitHub позволяют хранить материалы проекта в едином структурированном пространстве, отслеживать историю изменений и фиксировать вклад каждого участника. Ветки позволяют работать над отдельными изменениями независимо, а Pull Request и ревью помогают проверять изменения перед их объединением с основной веткой.
