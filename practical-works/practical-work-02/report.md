### 7. Вывод

Git и GitHub позволяют хранить материалы проекта в едином структурированном пространстве, отслеживать историю изменений и фиксировать вклад каждого участника. Ветки позволяют работать над отдельными изменениями независимо, а Pull Request и ревью помогают проверять изменения перед их объединением с основной веткой.
