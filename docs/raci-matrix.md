# Матрица RACI

**R (Responsible)** - исполнитель.  
**A (Accountable)** - ответственный за результат.  
**C (Consulted)** - консультируемый.  
**I (Informed)** - информируемый.

| Задача | Лидер | Программист | Дизайнер | Архитектор/тестировщик | Аналитик |
|---|---|---|---|---|---|
| Создание и настройка репозитория | A/R | I | I | C/R | I |
| Поддержание структуры репозитория | A | R | R | R | R |
| Подготовка отчётов | A | R | R | R | R |
| Создание осмысленных коммитов | A | R | R | R | R |
| Проверка Pull Request | A/R | C | C | R | C |
| Слияние веток в `main` | A/R | I | I | C | I |
| Поддержание актуальности репозитория | A | R | R | R | R |
